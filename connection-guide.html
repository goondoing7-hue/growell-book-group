01 · 홈 화면에 추가

갤럭시·안드로이드
홈 화면에 GROWELL 놓기

휴대폰과 갤럭시 탭에서 같은 순서로 진행해요. Chrome 기준 안내입니다.

  1. Chrome으로 사이트를 열어요.

    Chrome 주소창에 growell-book.vercel.app을 입력해요. 카카오톡 안에서 열린 경우에는 주소를 복사해 Chrome에서 다시 열어주세요.

  2. 오른쪽 위 더보기를 눌러요.

    주소창 옆 점 세 개 메뉴를 눌러 설치 및 바로가기 만들기 또는 홈 화면에 추가를 찾아요.

  3. 설치 또는 바로가기를 추가해요.

    설치가 보이면 선택해요. 바로가기 만들기가 보이면 이름을 GROWELL로 확인하고 추가해요. 마지막 기기 확인 창에서도 추가해주세요.

  4. 홈 화면에서 아이콘을 눌러요.

    GROWELL이 열리는지 확인해요. 로그인이 필요하면 기존 GROWELL 계정으로 로그인해주세요.

‘설치’가 없어도 괜찮아요.

브라우저 버전에 따라 ‘홈 화면에 추가’나 ‘바로가기 만들기’로 표시돼요. 홈 화면 아이콘으로 같은 사이트가 열리면 설정이 끝난 거예요.

02 · 홈 화면에 추가

아이폰·아이패드
Safari에서 홈 화면에 추가

Safari의 공유 메뉴를 사용해요. 아이패드는 공유 버튼이 위쪽에 있을 수 있어요.

  1. Safari에서 사이트를 열어요.

    Safari 주소창에 growell-book.vercel.app을 입력해요. 카카오톡의 내부 화면 대신 Safari로 열어주세요.

  2. 공유 버튼을 찾아요.

    사각형 위로 화살표가 올라가는 아이콘을 눌러요. 새 Safari에서는 페이지 메뉴를 연 다음 공유를 선택할 수도 있어요.

  3. ‘홈 화면에 추가’를 선택해요.

    공유 목록을 내려 홈 화면에 추가를 눌러요. 아이패드는 더 보기를 먼저 눌러야 할 수 있어요. 아이폰에서 항목이 없으면 동작 편집에서 추가해주세요.

  4. 이름을 확인하고 추가해요.

    이름을 GROWELL로 두고 웹 앱으로 열기가 보이면 켠 뒤 추가를 눌러요. 홈 화면 아이콘으로 열고 로그인해주세요.

홈 화면 추가와 알림 연결은 각각 설정해요.

아이콘 추가만으로 습관 알림이 연결되지는 않아요. Google Drive 백업과 습관 알림 연결을 이어서 설정해주세요. 기기·버전에 따라 메뉴 위치가 조금 다를 수 있어요.

03 · Google 연동

Google 기능을
필요한 만큼만 켜요.

백업·캘린더·PDF 이메일을 각각 ON/OFF로 선택해요.

  1. 프로필의 설정을 열어요.

    GROWELL에 로그인한 뒤 프로필 → 설정 → 연동으로 들어가요.

  2. 필요한 기능을 ON으로 바꿔요.

    Google Drive 백업·Google 캘린더·모임 기록 PDF 이메일 중 사용할 항목을 켜요. 별도 연결 버튼을 누르는 대신 해당 기능의 스위치를 사용해요.

  3. 처음에는 Google 동의를 마쳐요.

    필요한 연결이 없다면 본인 Google 계정을 선택하고 통합 권한 요청을 확인해요. GROWELL로 돌아오면 선택한 기능만 ON이 되고, 다른 항목의 OFF는 유지돼요. Google 로그인과 백업·캘린더 권한은 별도예요.

  4. 사용하는 앱에서 결과를 확인해요.

    백업은 내 Google Drive의 GROWELL 백업 폴더, 일정은 내 기본 Google 캘린더, PDF는 연결한 Google 이메일에서 확인해요. 첫 처리까지 잠시 걸릴 수 있어요. 모임 캘린더 자세히 보기

다른 기능이 저절로 켜지지 않아요.

백업만 켜면 캘린더와 PDF 이메일의 OFF 설정은 유지돼요. 사용하려는 기능을 각각 켜주세요.

Google 연동 · PDF 이메일

공개된 모임 기록을
내 이메일로 받아요.

모임 기록 PDF 이메일을 ON으로 두면 새로 공개된 기록을 받아요.

  1. PDF 이메일을 켜요.

    프로필 → 설정 → 연동 → 모임 기록 PDF 이메일을 ON으로 바꿔요. 백업이나 캘린더를 켰다고 이메일까지 켜지지는 않아요. 처음 켜면 가장 최근에 공개된 기록을 한 번 보내고, 이후 새 모임 기록마다 한 번씩 보내요.

  2. 첨부된 PDF를 열어요.

    연결한 Google 이메일에서 GROWELL 모임 기록 메일을 확인해요. PDF에는 운영자가 공개한 모임 기록과 같은 책·해당 회차의 회원 공개 통찰이 함께 담겨요. 나의 공간의 개인 기록과 공개하지 않은 글은 포함하지 않아요.

  3. 멈추려면 OFF로 바꿔요.

    같은 스위치를 OFF로 바꾸면 이후 자동 발송이 중지돼요. 이미 받은 이메일은 그대로 남아요. 이미 보낸 기록을 수정하거나 다시 열어도 메일을 반복해서 보내지 않아요.

메일이 보이지 않으면

받은편지함과 스팸함을 확인한 뒤 운영자에게 문의해주세요. 중복 메일을 막기 위해 결과를 확인할 수 없는 발송을 자동으로 다시 보내지는 않아요. 내 메일함을 읽거나 본인 계정으로 메일을 보내는 권한은 추가로 요청하지 않아요.

04 · 백업 확인과 관리

백업 파일은
내 Drive에서 확인해요.

내 계정의 최신 저장 상태를 JSON 파일로 보관해요.

  1. Drive에서 백업 폴더를 찾아요.

    Google Drive 앱이나 사이트에서 GROWELL 백업을 검색해요. 첫 백업이 끝나면 폴더 안에 GROWELL-backup.json이 보여요.

  2. 백업을 ON으로 두세요.

    프로필 → 설정 → 연동 → Google Drive 백업이 ON이면 저장한 변경 내용을 자동으로 반영해요. 처리까지 잠시 걸릴 수 있고, 브라우저를 닫아도 서버에서 이어가요.

  3. 잠시 멈추려면 OFF로 바꿔요.

    Google Drive 백업을 OFF로 바꾸면 이후 자동 백업이 중지돼요. Drive의 기존 백업 파일은 지우지 않아요.

복구 파일도 따로 보관해주세요.

프로필 수정 → 복구 파일 저장에서 보관할 수 있어요. 개인 기록의 열쇠는 Drive 백업에 포함하지 않아요. 백업 가져오기·자동 복원 화면은 제공하지 않으니 도움이 필요하면 운영자에게 문의해주세요.

어떤 내용이 저장되나요?

  • 나의 기록·독서 아카이브: 암호화된 개인 기록, 나의 책 정보·독서 진도·읽은 시간
  • 습관: 이름·목표·시간·요일과 전체 체크 기록
  • 나눔·자료실·활동지: 내가 작성한 글·댓글·답변과 저장된 영상·첨부 링크

초안이나 아직 저장하지 않은 내용, 다른 회원의 기록, 외부 첨부파일 원본, 영상 원본·자동 요약·스크립트, 별도 모임별 기록은 포함되지 않아요.

최신 상태를 보관하는 파일이에요.

수정 전 내용이나 삭제한 기록의 무제한 보관이나 자동 복원을 제공하는 파일은 아니에요. Drive 파일을 수정해도 GROWELL 기록에 반영되지 않아요.

암호화된 개인 기록을 열기 위한 복구 파일은 따로 보관해주세요. 백업 폴더는 다른 사람과 공유하지 말고 내 드라이브의 최상위에 두세요.

05 · 습관 알림 연결

먼저 GROWELL과
Microsoft 계정을 연결해요.

GROWELL → Microsoft To Do → 휴대폰 알림 앱 순서로 이어져요. 두 곳에서 같은 Microsoft 계정을 사용해주세요.

  1. 습관에서 알림 연결을 열어요.

    습관 → 전체 습관 한눈에 → 가치 습관 왼쪽 종 아이콘을 눌러요. Google 동의로 Microsoft 권한까지 연결되지는 않으니 처음 한 번은 아래 연결을 이어서 완료해주세요.

  2. Microsoft 계정을 연결해요.

    Microsoft 계정 연결을 눌러요. 본인의 계정으로 로그인하고 GROWELL의 작업 등록 권한에 동의해주세요.

  3. 자동 연동 설정을 확인해요.

    연동 설정 → 새 습관 자동 연동을 켜고 적용을 눌러요. 연결 이후 새 습관은 자동 등록 대상이 돼요.

  4. 기존 습관도 연결해요.

    아직 연동되지 않음 목록에서 연결할 습관의 연결을 눌러요. 연동 확인 중을 거쳐 연동됨으로 바뀌는지 확인해주세요.

아직 휴대폰 알림 설정이 남아 있어요.

연동됨은 Microsoft로 전달됐다는 뜻이에요. 삼성 리마인더 또는 아이폰·아이패드 미리 알림 설정까지 마쳐야 해당 앱에서 확인할 수 있어요.

06 · 시간과 요일 설정

각 습관에
요일과 시간을 정해요.

습관마다 다른 시간으로 설정할 수 있어요. 시간은 24시간 표기이며 10분 단위로 선택해요.

  1. 새 습관 또는 수정 화면을 열어요.

    새 습관 만들기를 누르거나 기존 습관의 수정 화면을 열어요. 습관 이름, 목표, 장소를 적어주세요.

  2. 시간 칸을 눌러 내려 골라요.

    빈 시간 칸을 누르면 아래로 선택 목록이 펼쳐져요. 13:00, 13:10, 13:20처럼 원하는 시간을 선택해주세요.

  3. 매일 또는 필요한 요일을 골라요.

    매일 할 습관은 매일을 선택해요. 특정 요일만 실천한다면 해당 요일만 고른 후 저장해주세요.

  4. 알림 앱의 일정도 확인해요.

    연동된 습관의 이름·목표·장소·시간·요일·기간을 GROWELL에서 변경하면 알림 앱에도 전달돼요. GROWELL에서 삭제한 습관도 연결된 알림에 반영돼요. 반영까지 잠시 걸릴 수 있으니 팝업의 새로고침 후 기기 앱에서도 확인해주세요.

시간·장소·완료 체크의 기준

시간은 한국 시간이에요. 빈 시간은 알림 없이 목록에만 등록돼요. 장소는 메모로 전달되며 위치 도착·출발 알림은 자동 설정되지 않아요. 휴대폰에서 완료해도 GROWELL 성공 체크는 바뀌지 않으니 실천한 날은 GROWELL에서도 따로 체크해주세요.

07 · 삼성 리마인더

갤럭시에서
GROWELL 습관 알림 받기

먼저 Microsoft 계정 연결을 마쳐주세요. 갤럭시 탭도 리마인더의 동기화 메뉴가 지원되면 같은 순서예요.

  1. 리마인더 설정을 열어요.

    삼성 리마인더 앱을 열고 메뉴에서 설정으로 들어가요. Microsoft To Do와 동기화를 선택해주세요.

  2. 같은 Microsoft 계정으로 로그인해요.

    GROWELL에서 연결한 Microsoft 계정으로 로그인하고 동기화를 허용해요. 동기화 스위치가 켜져 있는지 확인해주세요.

  3. 동기화할 목록을 골라요.

    리마인더의 To Do 탭에서 더보기 메뉴를 열어 동기화할 목록 선택으로 들어가요. GROWELL 목록을 골라주세요.

  4. 알림 표시와 시간을 확인해요.

    독서 등 연결한 습관을 열어 시간을 확인해요. 휴대폰 설정 → 알림 → 앱 알림 → 리마인더에서 알림을 허용하고 소리·방해 금지 설정도 확인해주세요.

GROWELL 목록이 안 보일 때

To Do 동기화를 켰는지, 같은 계정인지 확인해요. 설정의 지금 동기화를 실행해주세요. 삼성 리마인더는 한 번에 To Do 목록 한 개를 동기화하므로 다른 목록이 선택돼 있을 수 있어요.

08 · 애플 미리 알림

아이폰·아이패드에서
GROWELL 습관 확인하기

GROWELL의 Microsoft 계정을 기기의 미리 알림에도 연결해요. iCloud 목록이 아니라 Microsoft 계정의 목록에서 확인해주세요.

  1. 미리 알림 계정 설정으로 가요.

    설정 → 앱 → 미리 알림 → 미리 알림 계정 → 계정 추가로 이동해요. 구버전은 설정에서 미리 알림의 계정 메뉴를 찾아주세요.

  2. 계정 종류를 선택해요.

    개인 Microsoft 계정은 Outlook.com, 회사·학교 계정은 Microsoft Exchange를 선택해요. GROWELL에 연결한 같은 계정으로 로그인해주세요.

  3. ‘미리 알림’을 켜요.

    계정 동기화 항목에서 미리 알림 스위치를 켜고 저장해요. 이미 추가된 계정이라면 해당 계정 설정에서 스위치를 확인해주세요.

  4. Microsoft의 GROWELL 목록을 열어요.

    미리 알림 앱에서 전체 목록 화면으로 돌아가요. 연결한 Microsoft 계정 아래 GROWELL을 열어 습관을 확인하고, 기기 설정에서 미리 알림 알림을 허용해주세요.

‘미리 알림’ 항목이 없거나 목록이 안 보일 때

계정 종류와 회사·학교의 연결 정책을 확인해주세요. 기기에서 지원되지 않으면 Microsoft To Do 앱에 같은 계정으로 로그인해 GROWELL 목록을 이용할 수 있어요. 외부 계정의 기능은 iCloud와 다를 수 있어요.

자주 막히는 부분

Google로 로그인해도 기존 기록을 볼 수 있나요?

기존 아이디로 로그인한 상태에서 작성 중인 글을 먼저 저장하고 프로필 → 설정 → 연동 → Google 로그인 연결을 눌러주세요. 기존 비밀번호를 다시 입력하지 않고 Google 계정 선택 화면으로 이동해요. 본인 계정을 연결한 뒤에는 로그인 화면의 Google로 로그인을 이용해요. 회원 번호·글·습관·자료와 아이디 로그인은 유지해요. 새 기기에서 개인 기록을 처음 열 때는 현재 GROWELL 비밀번호가 필요해요. Google 비밀번호를 입력하는 칸이 아니에요. 이미 Google로 로그인한 경우 추가 로그인 연결 항목은 보이지 않아요. 백업·캘린더 권한 동의는 별도로 진행해요. Google 로그인 연결 방법 →

새 나눔·자료·매일 말씀 알림도 받을 수 있나요?

프로필 → 설정 → 알림에서 이 기기 알림을 ON으로 바꾸고 처음 뜨는 권한 요청을 허용해주세요. 그다음 새 나눔·자료 알림과 매일 오전 9시 말씀을 각각 ON/OFF로 선택해요. 내가 쓴 글과 글 수정은 제외하며, 말씀은 한국 시간 기준이에요. 아이폰·아이패드는 홈 화면에 추가한 GROWELL에서 켜주세요.

미연결 기기에는 로그인 후 알림 안내가 먼저 나타날 수 있어요. 알림 받기로 허용하거나 나중에로 7일 동안 안내를 미룰 수 있어요. 연결이 만료되면 이 기기 알림을 다시 켜주세요. 이전에 꺼둔 나눔·말씀 설정은 유지해요. 로그아웃하면 해당 기기 연결이 해제돼요. 푸시 알림 자세한 설정 방법 →

알림이 안 울려요.

시간과 요일, 알림 권한, 집중 모드·방해 금지, 인터넷 연결을 확인해주세요. 반복 알림은 앱에서 항목을 완료해야 다음 일정이 생기는 경우가 있어요. 이 완료 처리는 GROWELL 성공 체크와 별개예요.

알림 앱에서 수정하거나 완료했어요.

GROWELL로 역방향 반영되지는 않아요. 제목·일정 수정과 실천 기록은 GROWELL에서 관리해주세요. 외부 앱에서 삭제한 항목은 자동 복원되지 않아요. 연결 상태 안내를 확인하고 도움이 필요하면 운영자에게 문의해주세요.

알림 자동 연동을 잠시 멈추고 싶어요.

연동 설정 → 새 습관 자동 연동 → 적용에서 끄거나 다시 켤 수 있어요. 꺼져 있는 동안에는 기존 습관의 수정·삭제 전달도 대기해요. Microsoft 연결 해제는 자동 연동을 멈추고 연결 정보를 지우지만, 알림 앱에 이미 등록된 항목은 남아 있어요.

백업을 읽거나 예전 상태로 돌리고 싶어요.

백업은 최신 상태를 보관하는 JSON 파일이며 일부 개인 기록은 암호화돼 있어요. 과거 버전의 무제한 보관이나 자동 복원을 보장하지 않아요. 프로필 수정 → 복구 파일 저장에서 복구 파일도 따로 보관하고, 복원 도움이 필요하면 운영자에게 문의해주세요. 비밀번호나 복구 파일은 다른 사람에게 보내지 마세요.

안내와 내 기기의 메뉴가 조금 달라요.

이 가이드의 그림은 실제 메뉴 이름을 바탕으로 재구성한 안내용 예시예요. 기기·운영체제·계정 정책에 따라 메뉴 위치와 지원 범위가 다를 수 있어요. 회원의 글·사진·이메일은 사용하지 않았어요.
