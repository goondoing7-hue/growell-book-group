# 자료실 영상 재생과 자동 요약

자료글의 본문과 첨부 링크에서 YouTube 영상 ID를 확인하고, 상세 화면에 개인정보 보호 모드 플레이어를 표시합니다. 영상은 자동 재생하지 않습니다. 저장된 자료글에 실제로 포함된 영상만 서버에서 요약할 수 있습니다.

## 운영 준비

1. 같은 Supabase 프로젝트에 `server/material-video-summary.sql`을 실행합니다. 재실행할 수 있는 신규 캐시 표·사용량 표·RPC이며 기존 자료글을 바꾸지 않습니다.
2. 기존 `SUPABASE_SERVICE_ROLE_KEY`를 서버에서 사용합니다. 기본 프로젝트는 `oxaeecawijnetwmvggjs`이고 운영 요청 출처는 `https://growell-book.vercel.app`입니다.
3. 기본 AI 연결은 배포 서버의 Vercel OIDC 인증과 AI Gateway입니다. 해당 팀의 Gateway 사용 가능 여부와 잔액이 필요합니다. 별도 키가 있으면 서버 환경변수 `AI_GATEWAY_API_KEY` 또는 `GEMINI_API_KEY`를 사용할 수 있습니다. 키는 브라우저·Git·응답·로그에 넣지 않습니다.
4. 기본 모델은 무료 AI Gateway 크레딧 대상인 `google/gemini-2.5-flash`입니다. 2026-10-03 공식 모델 페이지의 Google 공급자 행에서 무료 대상 여부를 확인했습니다. 3.8 Flash는 무료 대상이 아니므로 기본으로 사용하지 않습니다. `GROWELL_VIDEO_MODEL`로 바꿀 수 있으며 Gateway는 `google/gemini-…`, Google 직접 연결은 `gemini-…` 형식입니다. 영상 URL 입력과 해당 계정의 사용 권한을 지원하는 모델을 사용합니다. 2.5 모델은 `thinkingBudget:0`, 3.x 모델은 `thinkingLevel:low`를 전달합니다.
5. 배포 뒤 승인 회원으로 실제 영상이 포함된 자료글을 열어 재생과 요약 생성을 확인합니다. 로컬 합성 응답·테스트 통과는 운영 AI 연결 성공을 뜻하지 않습니다.

## 데이터와 동작

- 요청은 회원 인증 토큰, 자료글 ID와 영상 ID만 받습니다. 서버에서 승인 상태와 해당 글의 RLS 접근 권한, 저장된 영상 링크를 다시 검증합니다.
- AI 서비스에는 정규화한 공개 YouTube URL과 고정된 요약 지시만 보냅니다. 회원 정보·자료글 본문·개인 메모는 보내지 않습니다.
- 한 번 만든 영상 요약은 서버에 보관하여 재사용합니다. 요약 캐시와 아래의 원문 자막 캐시는 별도이며, 각 표와 RPC는 `service_role`만 접근합니다.
- 동시 요청은 90초 생성 임대로 중복 처리를 막습니다. 새 생성은 한국 날짜 기준 전체 50회/일, 회원 10회/일까지 허용합니다. 기존 요약을 읽는 것은 생성 횟수에 포함하지 않습니다.
- 생성은 최대 40초, 서버 요청은 최대 50초로 제한합니다. 영상 확인 불가·설정 누락·한도·일시 오류는 구분하여 안내하며 임의로 요약을 만들어내지 않습니다. 오류 종류에 따라 5분~24시간 뒤 재시도할 수 있습니다.
- 영상 자체가 비공개·삭제·연령 제한·외부 재생 제한이면 YouTube 정책에 따라 재생이나 요약이 불가능할 수 있습니다.

## 전체 스크립트·인쇄 연결

1. 같은 Supabase 프로젝트에 `server/material-video-transcript.sql`을 적용한 뒤 `server/material-video-translation.sql`을 적용합니다. 원문과 번역은 별도 표·RPC를 사용하며 기존 자료글·요약을 바꾸지 않습니다. 번역 표는 원문 표를 참조하므로 이 순서를 지킵니다.
2. Supadata 무료 계정의 API 키를 Vercel 운영 환경의 `SUPADATA_API_KEY`에 저장합니다. AI 번역은 위의 영상 요약과 같은 서버 AI 인증을 사용합니다. 키를 Git·브라우저·로그에 넣지 않으며 무료 계정 외의 구독·자동 충전은 별도 승인 없이 설정하지 않습니다.
3. 자료글을 저장하면 상세 화면으로 이동하고, 기존 글도 상세 화면을 열면 승인 회원의 접근권한을 확인한 뒤 공개 자막을 가져옵니다. Supadata에는 정규화한 공개 YouTube URL과 언어 선택만 보냅니다. 실제 영상 제목은 `materialVideoMetadata.cjs`가 공개 YouTube oEmbed에서 조회하며 제목 조회 실패가 자막 열람을 막지는 않습니다.
4. 원문 조회는 `mode=native`, `text=true`로 한국어를 우선하고 영어를 다음으로 선택합니다. 한국어 요청에 자막 없음이 반환되어도 영어를 한 번 확인하며, 추가 요청은 별도로 사용량을 예약합니다. AI 전사로 원문을 만들지 않습니다. 원문 버전 3에는 가져온 본문·언어·실제 영상 제목·시각을 저장하며 번역을 생성해도 원문을 수정하지 않습니다. 저장한 원문을 다시 읽거나 인쇄할 때는 새 자막을 추출하지 않습니다.
5. 한국어 자막 대신 영어 원문을 가져왔으면 AI 한국어 번역을 별도로 준비합니다. 원문을 저장한 첫 응답은 번역 준비 상태를 알리고, 다음 요청에서 번역을 생성하여 한 요청에 자막 추출과 번역의 긴 작업이 겹치지 않게 합니다. 준비 중에도 원문을 열 수 있으며 화면의 자동 확인은 최대 4회입니다.
6. `전체 스크립트`는 한국어 자막 또는 준비된 `AI 한국어 번역`을 기본으로 표시합니다. 번역과 영어 원문을 버튼으로 전환할 수 있고 `인쇄 · PDF 저장`은 선택한 글·실제 영상 제목·언어·출처·가져온 시각을 담습니다. 번역을 인쇄하면 AI 번역 표시와 번역 시각도 포함합니다. 앱 메뉴와 영상 플레이어는 인쇄하지 않습니다.

기존 공개 자막이 없거나 영상 접근이 제한되면 원문 없음 상태를 표시합니다. 원문을 얻지 못했을 때 AI로 대본을 만들어 채우지 않습니다. 한국어 번역을 준비할 수 없으면 저장한 영어 원문을 그대로 제공하고, 영어 외의 자막도 가져온 언어를 밝힙니다. 자막 부재는 7일, 원문 조회의 일시 오류는 15분 동안 재시도를 제한합니다. 제공자 키가 없어도 저장된 원문은 승인 회원의 접근권한을 확인한 뒤 읽을 수 있습니다.

### 번역 보관과 사용량

- 번역은 영어 원문에만 적용합니다. 원문이 60,000자를 넘으면 잘라 번역하거나 일부 번역을 완성본으로 표시하지 않고 영어 원문을 제공합니다. 이 제한은 자막 원문 저장·열람을 제한하지 않습니다.
- 번역 캐시의 고유 키는 `(video_id, transcript_version, translation_version)`이며 생성 ID를 별도로 보관합니다. 같은 원문·번역 버전의 재열람은 저장본을 읽습니다. 실패·중단된 생성 시도도 보존하므로 새로고침이나 다른 회원의 열람으로 같은 유료 번역을 반복하지 않습니다. 부분 결과는 운영 확인용으로만 보관하고 완성된 번역처럼 표시하지 않습니다.
- 번역 본문·생성 시각·모델·입력/출력 토큰·처리 시간과 상태를 서버에 보관합니다. 원문은 `youtube_captions`, 번역은 `ai_translation`으로 구분합니다. 번역 캐시와 RPC도 `service_role`만 접근하며, 화면에 반환하기 전에 승인 상태와 자료글 접근권한을 다시 확인합니다.
- 새 번역 시도는 한국 날짜 기준 전체 20회/일·회원 10회/일·최근 31일 100회로 제한합니다. 동시 요청은 저장소의 잠금과 생성 ID로 한 번만 생성되도록 처리합니다. 저장된 번역 열람은 생성 한도를 사용하지 않습니다.
- 최초 AI 번역에는 AI 크레딧이 사용됩니다. 저장을 완료한 번역의 재열람·원문 전환·인쇄에는 추가 번역 크레딧이 들지 않습니다. 실패 전에 제공자 처리가 시작되었다면 크레딧이 소모될 수 있으므로 실패를 숨기고 자동으로 재생성하지 않습니다. 영상 요약, 자막 조회, 한국어 번역은 서로 별도의 작업이며 구체적인 금액은 추정하지 않습니다.

2026-10-03 기준 Supadata 무료 제공량은 월 100크레딧이며 기존 자막 요청은 성공·206 부재 응답 모두 1크레딧, 작업 상태 조회는 0크레딧입니다. 자막 조회의 새 요청에도 전체 20회/일·회원 10회/일·최근 31일 100회 제한을 별도로 적용합니다. 같은 키를 다른 곳에서 사용한 사용량까지 통제하지는 않습니다. 202 작업은 동일 작업만 최대 10회·10분 조회하며 새 추출로 조용히 바꾸지 않습니다.

이 절은 구현·설정 안내이며 운영 연결 완료 기록이 아닙니다. SQL 적용과 배포 후 실제 공개 영상에서 한국어 자막 우선 선택, 실제 제목, 영어 원문의 한국어 번역, 원문 전환과 선택 인쇄를 확인합니다. 재열람 때 원문 저장 시각·번역 생성 ID가 유지되는지, 자막 없음·번역 실패가 정직하게 안내되는지도 확인합니다. 로컬 합성 응답·테스트 통과만으로 외부 서비스 연결 완료라고 표시하지 않습니다.

공식 연결 규격: [Supadata 원문 API](https://docs.supadata.ai/get-transcript), [무료 제공량](https://supadata.ai/pricing).

## 검증 실행

`npm.cmd run build`는 영상 ID·실제 제목·원문과 번역 출력, 인증·접근권한, 취소·시간 제한, PostgreSQL의 중복 생성 차단·사용량 제한·RLS, 화면 전환·선택 인쇄를 검증합니다. 실제 회원 글을 생성하거나 변경하지 않는 별도 로컬 합성 화면으로 UI를 확인합니다.
