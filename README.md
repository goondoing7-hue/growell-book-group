# GROWELL 독서모임

GROWELL 독서모임의 웹 앱입니다. 앱 소스와 검증 코드를 GitHub에서 관리하고, 연결된 Vercel 프로젝트가 검사·테스트를 통과한 정적 파일만 배포하도록 구성했습니다.

## 파일 구성

- `index.html`: 화면, 로그인, 독서 기록, 습관, 임시 저장 등 앱 코드
- `privateCrypto.js`: 개인 기록 암호화와 복구 파일 처리
- `privacy.html`: 로그인 없이 읽는 개인정보 안내
- `home.css`, `homeDomain.js`: PC·모바일 홈 스타일과 독서·습관·최신 공유 글 선택
- `readingTimer.css`, `readingTimerDomain.js`: 독서 타이머 화면과 경과 시간·카운트다운·복원·쪽수 검증
- `covers/`, `manifest.json`: 책 표지, 아이콘, 설치용 앱 정보
- `tests/`: 실제 회원 데이터 없이 실행하는 회귀 검사
- `scripts/`: 소스 검사, 테스트, 빌드, 제한된 Git 게시 명령
- `dist/`: 빌드 때 생성하는 공개 배포 파일. Git에는 올리지 않습니다.

## 검증과 빌드

Node.js 22 이상과 Git이 필요합니다. Windows PowerShell에서는 `npm.cmd`를 사용합니다. 이 프로젝트에는 설치해야 할 npm 외부 의존성이 없습니다.

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
```

빌드는 스크립트 문법·로컬 이미지 연결을 검사하고, 모든 등록된 테스트를 실행한 뒤 공개 파일만 `dist/`로 복사합니다. 검사에 실패하면 배포 파일을 새로 만들지 않습니다.

각 단계만 따로 실행할 수도 있습니다.

```powershell
npm.cmd run check
npm.cmd test
```

## 수정한 내용 게시

`goondoing7-hue/growell-book-group` 저장소의 루트에서 실행합니다.

```powershell
npm.cmd run publish -- "독서 기록 저장 개선"
```

이 명령은 원격 변경을 확인하고 검증·빌드한 뒤 허용된 소스 파일만 커밋하여 현재 브랜치에 푸시합니다. `main`은 운영 배포, 다른 브랜치는 Vercel Preview에 사용합니다. 프로젝트 연결과 확인 순서는 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요.

## 첫 화면과 로그인 홈

PC에서는 독서·습관·개인 기록·모임을 두 열로, 모바일에서는 간결한 한 열로 표시합니다. 이어서 읽기는 가장 최근에 진도를 저장한 열린 책을 우선하며, 없으면 공지의 책을 사용합니다. 홈의 습관은 오늘이 실천 기간인 본인 습관이고, 체크는 기존 습관 화면과 같은 저장 큐를 사용합니다.

습관 종류는 체크 원 아이콘의 **실천할 습관**과 손바닥 아이콘의 **절제할 습관** 중 하나만 고르면 됩니다. 두 종류 모두 약속을 지킨 날을 성공으로 체크하며, 기존 습관은 실천할 습관으로 유지됩니다. 이 기능의 첫 배포 전 `server/habit-kind.sql`을 적용합니다.

로그인 전에는 회원 가입·로그인을 안내합니다. 나눔 공간, 나의 공간, 활동지, 자료실과 습관은 로그인 후 이용합니다. 소개와 전체 독서 여정은 `#/about`에서, 개인정보 안내는 `privacy.html`에서 로그인 없이 볼 수 있습니다.

모임원의 새 글은 열린 책의 공개 공유 글 중 최신 3개이며, 로그인 시 본인 글을 제외합니다. 전체 보기는 20개씩 표시하고, 기존 글 상세·댓글로 연결합니다. 개인 기록·활동지 내용은 이 목록에 포함하지 않습니다. 모임 안내 편집과 전체 독서 여정은 홈의 안내 버튼과 하단 링크에서 계속 이용할 수 있습니다.

## 독서 타이머와 글 색상

홈의 **타이머로 읽기 시작** 또는 나의 공간의 타이머 버튼으로 독서를 시작합니다. 일시정지·계속 읽기, 10·20·30분 빠른 선택과 시간·분 슬라이더 카운트다운을 지원합니다. 목표 시간이 되면 자동으로 멈추고 **어디까지 읽으셨나요?** 화면을 엽니다. 페이지 슬라이더와 미세 조정으로 마지막 쪽수·책 전체 대비 비율을 확인하거나 **이 책 다 읽었어요**를 선택하고 저장하면 홈 진도·오늘/누적 시간과 읽은 기록에 반영됩니다. 책의 쪽수를 다시 바꾸려면 기존 현재 페이지 수정 기능을 사용합니다.

타이머의 노트 버튼에서 나눔 공간 또는 나의 공간을 고르면 기존 글쓰기 도구로 기록할 수 있습니다. 작성 중에는 타이머를 멈추고 저장 후 같은 타이머로 돌아오며, 작성 전에 진행 중이었다면 시간을 이어갑니다.

진행 중인 타이머와 저장 전 쪽수는 같은 계정의 현재 브라우저에 보관됩니다. 화면 이동·새로고침·백그라운드에서도 시간 기준으로 이어지며, 로그아웃하면 일시정지됩니다. 저장을 마친 독서 기록은 기존 서버에 저장되어 다른 기기에서도 확인할 수 있습니다. 서버 저장이 실패하면 같은 기록 ID·시간으로 재시도하여 중복을 방지합니다. 카운트다운은 앱 내 표시이며 운영체제 알람을 예약하지 않습니다.

글자색과 형광펜은 각각 **옆 화살표 → 색 선택**으로 아이콘의 현재 색을 바꿉니다. 본문에서 글자를 선택한 뒤 **아이콘 본체**를 누르면 그 색이 적용됩니다. 두 도구의 색은 독립적이며 기존 굵게·밑줄·목록·링크·사진·배경색·글자 크기 기능도 유지합니다.

## 가입·프로필과 관리자

일반 아이디 가입과 Google·카카오 간편 가입을 연결했습니다. 가입 후 별명·프로필 사진은 프로필 메뉴에서 바꿀 수 있습니다. 소셜 가입에는 별도의 개인 기록 비밀번호를 사용하며 별명·이메일 일치로 기존 회원을 합치거나 관리자 권한을 부여하지 않습니다. 2026-09-23에 Google 앱의 공개 게시와 ‘프로덕션 단계’ 상태를 확인했습니다. 운영 검증 상태와 소셜 비밀번호 복구·탈퇴의 현재 범위는 [AUTH_SETUP.md](AUTH_SETUP.md)를 확인하세요.

## 개인 기록 복구 파일

앱에서 내려받은 `growell-recovery-*.json`에는 개인 기록을 복구하는 데 필요한 비밀 정보가 있습니다. 소스 폴더에 두지 않고 개인 보관 장소에 저장합니다. 복구 파일, `.env`, 테스트 데이터, 브라우저에서 추출한 회원 데이터를 Git 또는 배포 파일에 넣지 않습니다. 공개 Supabase 클라이언트 설정과 비공개 서버 키는 용도가 다르며, 서버의 service role 키를 프런트엔드에 넣어서는 안 됩니다.
